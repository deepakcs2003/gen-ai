CHAPTER 1: UNDERSTANDING AGENTS - The Smart Decision Makers

🤖 What is an Agent?

Simple Definition: An Agent is an AI that can THINK, DECIDE, and USE TOOLS to accomplish a task.

🔄 Chain vs Agent (Critical Difference!)

⛓️ CHAIN (The Recipe)

Linear Path

Input → LLM → Output

Behavior: Fixed path, no decisions.

Analogy: Following a strict recipe.

  • Step 1: Boil water
  • Step 2: Add pasta
  • Step 3: Cook 10 mins
Use when: Task is predictable (e.g., Translation).

🕵️ AGENT (The Chef)

Dynamic Loop

Goal → Think ⟳ Tools → Result

Behavior: Thinks, decides, adapts.

Analogy: A Chef cooking.

  • Goal: Make dinner
  • Thinks: "No pasta? I'll make rice."
  • Uses: Stove, Pantry.
Use when: Multi-step tasks requiring external tools.

CHAPTER 2: HOW AGENTS WORK - The ReAct Framework

🧠 The ReAct Pattern (Reasoning + Acting)

Agents use a pattern called ReAct:

1. THOUGHT
Agent thinks about what to do next.
2. ACTION
Agent decides which tool to use.
3. OBSERVATION
Agent sees the result from the tool.
4. REPEAT
Loop continues until the final answer is found.

The Agent Loop (Visual)

USER: "What's 25 * 17 + 100?"

🔽 THOUGHT 1: "I need to calculate 25 * 17 first."

⚙️ ACTION 1: Use Calculator [Input: 25*17]

👀 OBSERVATION 1: 425


🔽 THOUGHT 2: "Now add 100 to 425."

⚙️ ACTION 2: Use Calculator [Input: 425+100]

👀 OBSERVATION 2: 525

🏁 FINAL ANSWER: "The answer is 525"

Real ReAct Example Output

Terminal Output 
Question: What's the weather in Paris and should I bring an umbrella?

Thought: I need to find the current weather in Paris
Action: weather_tool
Action Input: Paris
Observation: Current weather: Rainy, 15°C, 80% chance of rain

Thought: It's rainy, so an umbrella is recommended
Final Answer: The weather in Paris is rainy (15°C). Yes, you should 
definitely bring an umbrella as there's an 80% chance of rain.

CHAPTER 3: TOOLS - Giving Agents Superpowers

🛠️ What are Tools?

Tools are functions capabilities that agents can use. Think of them as the agent's hands.

🔍 Search Tools
  • Google Search
  • Wikipedia
🧮 Calculation Tools
  • Calculator
  • Python REPL
📊 Data Tools
  • SQL Database
  • API Calls
📝 Action Tools
  • Send Emails
  • Write Files

Anatomy of a Tool

tool_structure.py 
Tool(
    name="calculator",          # 1. NAME: What it's called
    description="Useful for math", # 2. DESC: When to use it
    func=calculate_function     # 3. FUNC: What it does
)

EXAMPLE 1: Creating a Simple Custom Tool

example1_custom_tool.py 
# Imports
from langchain.agents import Tool
from langchain_google_genai import ChatGoogleGenerativeAI
import os

# Setup API
os.environ["GOOGLE_API_KEY"] = "YOUR_API_KEY_HERE"

# Step 1: Define a simple tool function
def get_word_length(word: str) -> str:
    """Returns the length of a word"""
    return f"The word '{word}' has {len(word)} letters."

# Step 2: Create a Tool object
word_length_tool = Tool(
    name="WordLength",
    func=get_word_length,
    description="Useful when you need to find how many letters are in a word."
)

# Step 3: Test the tool directly
print(word_length_tool.run("elephant"))
# Output: The word 'elephant' has 8 letters.

EXAMPLE 2: Multiple Tools - Calculator & Word Counter

example2_multi_tools.py 
from langchain.tools import Tool

# Tool 1: Calculator
def calculator(expression: str) -> str:
    try:
        result = eval(expression)
        return f"The result is: {result}"
    except:
        return "Invalid math expression"

calc_tool = Tool(
    name="Calculator",
    func=calculator,
    description="Useful for math. Input: expression like '25 * 4'"
)

# Tool 2: Word Counter
def count_words(text: str) -> str:
    word_count = len(text.split())
    return f"The text has {word_count} words."

word_counter_tool = Tool(
    name="WordCounter",
    func=count_words,
    description="Counts words in text."
)

# Test both tools
print(calc_tool.run("100 + 50 * 2"))
print(word_counter_tool.run("The quick brown fox jumps"))

EXAMPLE 3: Building Your First Agent

example3_first_agent.py 
from langchain.agents import create_react_agent, AgentExecutor
from langchain import hub
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.tools import Tool

# Step 1: Setup LLM
llm = ChatGoogleGenerativeAI(model="gemini-1.5-flash", temperature=0)

# Step 2: Create tools (Using previous functions)
tools = [
    Tool(
        name="Multiply",
        func=lambda x: str(float(x.split('*')[0]) * float(x.split('*')[1])),
        description="Multiplies two numbers. Input: 'num1 * num2'"
    ),
    Tool(
        name="Add",
        func=lambda x: str(float(x.split('+')[0]) + float(x.split('+')[1])),
        description="Adds two numbers. Input: 'num1 + num2'"
    )
]

# Step 3: Get ReAct prompt
prompt = hub.pull("hwchase17/react")

# Step 4: Create agent
agent = create_react_agent(llm=llm, tools=tools, prompt=prompt)

# Step 5: Create executor
agent_executor = AgentExecutor(
    agent=agent, 
    tools=tools, 
    verbose=True # Shows thinking process
)

# Step 6: Run
response = agent_executor.invoke({
    "input": "What is 25 multiplied by 4, then add 100?"
})

print("\nFINAL ANSWER:", response['output'])

CHAPTER 7: MEMORY - Making AI Remember

[Image of AI conversational memory integration architecture]

🧠 Why Memory?

❌ Without Memory

My name is John
Hi John!
[Memory Cleared]
What's my name?
I don't know. 😞

✅ With Memory

My name is John
Hi John!
[Saved to Memory]
What's my name?
Your name is John! 😊

Memory Types

  • ConversationBufferMemory: Stores EVERYTHING. Simple but token heavy.
  • ConversationBufferWindowMemory: Stores last N messages. Prevents overflow.
  • ConversationSummaryMemory: Stores a summary of the chat.
  • ConversationEntityMemory: Remembers specific facts (Names, Places).

CHAPTER 8: IMPLEMENTING MEMORY

EXAMPLE 6: ConversationBufferMemory (Basic)

example6_buffer_memory.py 
from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain

memory = ConversationBufferMemory()

conversation = ConversationChain(
    llm=llm,
    memory=memory,
    verbose=True
)

# Conversation 1
conversation.predict(input="Hi! My name is Sarah.")

# Conversation 2 - AI Remembers!
response = conversation.predict(input="What's my name?")
print(response) # Output: "Your name is Sarah"

EXAMPLE 7: ConversationBufferWindowMemory (Last N)

example7_window_memory.py 
from langchain.memory import ConversationBufferWindowMemory

# Only remember last 2 interactions
memory = ConversationBufferWindowMemory(k=2) 

conversation = ConversationChain(llm=llm, memory=memory)

conversation.predict(input="I like Blue")
conversation.predict(input="I like Pizza")
conversation.predict(input="I like Coding")

# Ask about Blue (It forgot, because it was 3 turns ago)
response = conversation.predict(input="What color do I like?")
print(response) # AI might not know

EXAMPLE 8: ConversationSummaryMemory

example8_summary_memory.py 
from langchain.memory import ConversationSummaryMemory

# Uses LLM to summarize conversation constantly
memory = ConversationSummaryMemory(llm=llm)

conversation = ConversationChain(llm=llm, memory=memory, verbose=True)

conversation.predict(input="I am a software engineer in SF.")
conversation.predict(input="I have been coding for 10 years.")

print(memory.load_memory_variables({}))
# Output: "The human is a software engineer in SF with 10 years exp."

CHAPTER 9: MEMORY WITH AGENTS

🔗 Combining Agents + Memory

Agents with memory can execute tasks while remembering context from previous turns.

EXAMPLE 9: Agent with Conversational Memory

example9_agent_memory.py 
from langchain.agents import create_react_agent, AgentExecutor
from langchain.memory import ConversationBufferMemory
from langchain.tools import Tool

# 1. Setup Memory
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)

# 2. Simple Tools
def calc(x): return str(eval(x))
tools = [Tool(name="Calc", func=calc, description="Math tool")]

# 3. Create Agent
agent = create_react_agent(llm=llm, tools=tools, prompt=hub.pull("hwchase17/react"))

# 4. Executor WITH Memory
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    memory=memory, # <--- CRITICAL: Pass memory here
    verbose=True
)

# 5. Usage
print("Q1:")
agent_executor.invoke({"input": "Calculate 50 * 20"})

print("\nQ2:")
# The agent remembers the previous answer (1000)
agent_executor.invoke({"input": "What was that result plus 500?"})
